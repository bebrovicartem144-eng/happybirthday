# Персональный сайт-поздравление для Насти (16 лет) от Артёма

Готовый проект для загрузки на любой хостинг (GitHub Pages, Netlify, Vercel, Timeweb, Reg.ru и др.).

## Состав файлов
- `index.html` — главная страница сайта с конвертом, биркой «Для Насти ♥» и персональным письмом-поздравлением с 16-летием от Артёма (без кнопок редактирования).
- `style.css` — таблица стилей, 3D-анимация открытия конверта, падающие лепестки и оформление открытки.
- `script.js` — многоголосный акустический синтезатор рояля и тёплых струнных с эффектом концертного зала (Web Audio API Convolution Reverb + Grand Piano + String Pad), анимация лепестков роз и салюта из сердечек.
- `floral_banner.jpg` — романтическая акварельная иллюстрация в шапке открытки.

## Как выложить на хостинг
Загрузите все 4 файла (`index.html`, `style.css`, `script.js`, `floral_banner.jpg`) в одну корневую папку вашего хостинга или репозитория.
